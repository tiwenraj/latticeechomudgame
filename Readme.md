# Lattice Echo

An original terminal-based sci-fi cyberpunk MUD.

## Features
- Single-player practice mode
- Multiplayer server mode
- PvE combat
- PvP toggle
- Text-based command gameplay

## Commands
help, look, status, inventory, north, south, east, west, take ITEM, attack ENEMY, quests, say MESSAGE, pvp on, pvp off, quit
